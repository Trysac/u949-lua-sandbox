# Architecture

`trysac::lua_sandbox` wraps the Lua 5.5 C API. It provides a `Sandbox` class that manages execution via a dedicated `lua_State` per `run()` call. Memory tracking is performed via a custom `lua_Alloc` callback. Execution monitoring is performed by `lua_sethook` for instructions (1,000-count interval) and call depth tracking. Host functions are invoked via a C trampoline that captures C++ exceptions to ensure `lua_error` is called only after destructors run.
